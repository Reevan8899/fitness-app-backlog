## Запуск

Требуется Node.js 22+. Выполните `npm ci`, `npm test`, `npm run smoke`, затем `npm start`. Форма: http://127.0.0.1:3000.

Учебный стенд использует хранилище в памяти и тестовый почтовый outbox.
